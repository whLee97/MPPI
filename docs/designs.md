# Simulation Designs

The simulations include twelve scenarios with 1,000 replications each. All settings use three sources, two covariates, a target sample size of 5,000, source sample sizes of 10,000, 20,000, and 30,000, five-fold cross-fitting, and a nominal significance level of 0.05.

Source-specific predictors are fitted on independent labeled auxiliary samples and remain fixed during inference.

## Simulation Scenarios

| Scenario | Distribution | Target | DGP |
| --- | --- | --- | --- |
| 1, 2, 3 | Homogeneous / Covariate shift / Domain shift | Mean | Linear |
| 4, 5, 6 | Homogeneous / Covariate shift / Domain shift | Regression | Linear |
| 7, 8, 9 | Homogeneous / Covariate shift / Domain shift | Mean | Nonlinear |
| 10, 11, 12 | Homogeneous / Covariate shift / Domain shift | Regression | Nonlinear |

## Covariate Distributions

**Homogeneous setting.** Target and source covariates follow the same standard bivariate normal distribution, `N(0, I_2)`.

**Covariate shift.** Target covariates follow `N(0, I_2)`. Source covariates have covariance `I_2` and means `(-0.5,-0.5)`, `(-1,-1)`, and `(1.5,1.5)`, respectively.

**Domain shift.** Target and source latent covariates have independent standardized Logistic coordinates:

`Z_j = sqrt(3)/pi * L_j`, where `L_j ~ Logistic(0,1)`.

For source `s = 1,2,3`, the observed covariates are generated by

`X_s = A_s Z_s + b_s`,

where

- `A_s = diag(1 + 0.05*s*(0.5,1))`
- `b_s = s*(0.05,-0.025)`

The domain-shift procedure uses affine transport to align source covariates with the target distribution.

## Data-Generating Processes

All response models include independent Gaussian noise with mean zero and variance one.

### Mean Estimation

For homogeneous and covariate shift:

- Linear: `g(X) = 1.2*X1 - 0.8*X2`
- Nonlinear: `g(X) = 2*X1 + sin(2*pi*X1) - 0.8*X2`

The target population mean is zero.

For domain shift:

- Linear: `g(Z) = 1 + 1.2*Z1 + 1.2*Z2`
- Nonlinear: `g(Z) = 1 + h_L(Z1) + h_L(Z2)`

where

`h_L(z) = (z^3 - m4*z)/sqrt(m6 - m4^2)`,

with `m4 = 21/5` and `m6 = 279/7`.

The target population mean is one.

### Regression Coefficients

The target parameter is the no-intercept population least-squares coefficient

`beta = (1.2,-0.8)`.

For homogeneous and covariate shift:

- Linear: `g(X) = 1.2*X1 - 0.8*X2`
- Nonlinear: `g(X) = 1.2*X1 - 0.8*X2 + (X1^2-1) + (X2^2-1)`

For domain shift:

- Linear: `g(Z) = 1.2*Z1 - 0.8*Z2`
- Nonlinear: `g(Z) = 1.2*Z1 - 0.8*Z2 + q_L(Z1) + q_L(Z2)`

where

`q_L(z) = c_L*(z^2-1)`.

The implementation uses `c_L = 0.555`, a rounded approximation to the analytic normalization constant `0.5550662947`. This gives the corresponding normalization moment approximately `9.99761` rather than exactly `10`. The implemented value is retained to reproduce the provided reference results.

## Auxiliary Predictors

All auxiliary predictors are fitted using ordinary least squares.

For homogeneous and covariate shift:

- Mean estimation and linear regression use the two covariates without an intercept.
- Nonlinear regression uses complementary quadratic features. Sources 1 and 2 include `X1^2-1` and `X2^2-1`, respectively, while source 3 uses only the intercept and linear covariates.

For domain-shift mean estimation:

- Linear DGP: sources 1 and 2 use `(1,u1^3)` and `(1,u2^3)`, respectively.
- Nonlinear DGP: sources 1 and 2 use `(1,u1,u1^3)` and `(1,u2,u2^3)`, respectively.
- Source 3 uses an intercept-only predictor in both cases.

Here `u_j` denotes the corresponding covariate standardized using its auxiliary training sample.

For domain-shift linear regression, sources 1, 2, and 3 use the auxiliary response signals `1.2*Z1`, `-0.8*Z2`, and `1.2*Z1-0.8*Z2`, respectively. All three predictors use the observed features `(1,X1,X2)`.

For domain-shift nonlinear regression, the source predictors use the same complementary quadratic feature structures as in the homogeneous and covariate-shift settings.

## Methods and Evaluation

Nine methods are compared:

- MPPI
- Classic
- Equal Weighting (EW)
- PPI (Sources 1–3)
- PPI++ (Sources 1–3)

All methods use the same inference data and auxiliary predictors within each replication.

The reported criteria include empirical coverage probability (ACP), the estimated asymptotic covariance determinant (Vol), and rejection probabilities. Regression rejection curves average over 100 directions at each positive radius.
